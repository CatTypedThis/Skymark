# Sky Beacon

Sky Beacon is an augmented-reality camera app concept for placing tall, sky-reaching beacons in the real world. The project currently includes a product requirements document and high-definition UI mockups.

## Files

- `PRD.md` - product requirements for the Sky Beacon app.
- `UI.html` - interactive high-definition UI mockups.
- `assets/` - visual assets used by the mockups.
